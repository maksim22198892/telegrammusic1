# Telegram Music — Render Edition

Telegram Mini App для прослушивания аудио, опубликованного в твоём Telegram-канале. Оригинальные аудиофайлы остаются в Telegram; приложение хранит в PostgreSQL каталог и Telegram `file_id`, а backend передаёт аудио в плеер.

## Самый простой запуск на Render (через браузер)

1. Распакуй ZIP на компьютере. Внутри должна быть папка проекта с `package.json`, `render.yaml`, `backend/` и `frontend/`.
2. Создай приватный GitHub-репозиторий и загрузи в него **содержимое** папки проекта (не ZIP-файл). Не загружай токены и `.env` файлы.
3. В Render Dashboard выбери **New → Blueprint** и подключи репозиторий. Render прочитает `render.yaml` и предложит создать Web Service и PostgreSQL.
4. Подтверди создание ресурсов. Blueprint попросит значение `BOT_TOKEN` — вставь токен бота из BotFather только в Render, не в GitHub и не в чат. `TELEGRAM_WEBHOOK_SECRET` и `SESSION_SECRET` Render сгенерирует автоматически.
5. Дождись успешного deploy. Открой адрес сервиса `https://...onrender.com`; `/api/health` должен вернуть JSON с `ok: true`.
6. Добавь бота администратором в свой музыкальный канал. После публикации первой новой песни Telegram отправит `channel_post`, приложение автоматически привяжет этот канал как источник.
7. В `@BotFather` открой настройки бота → **Bot Settings → Configure Mini App** (или Main App, в зависимости от интерфейса) и укажи публичный HTTPS URL сервиса Render.
8. Открой Mini App через кнопку бота. Публикуй аудио в канале как **Audio**; новые треки появятся в каталоге.

### Настройки Render

Blueprint создаёт один Node.js Web Service и одну PostgreSQL базу. Backend автоматически регистрирует Telegram webhook при старте, используя `RENDER_EXTERNAL_URL`; отдельная команда в Shell не нужна.

Команды сборки и запуска: `npm install && npm run build` и `npm start`.

## Важные ограничения бесплатного плана Render

- Бесплатный Web Service засыпает после 15 минут без входящих запросов и обычно просыпается примерно за минуту.
- Бесплатная PostgreSQL база Render действует 30 дней, имеет лимит 1 ГБ и не имеет резервных копий. До истечения срока её нужно перевести на платный тариф, иначе после дополнительного льготного периода данные будут удалены.
- Бесплатный план подходит для проверки MVP, но не для постоянного музыкального сервиса.

## Ограничения Telegram

- Обычный Bot API позволяет скачивать через `getFile` файлы размером до 20 МБ. Для больших файлов нужен собственный Local Bot API Server.
- Бот получает новые публикации канала после подключения и установки webhook. Bot API не предоставляет историю старых публикаций; для старого каталога нужен отдельный импорт.
- Бот должен быть администратором канала. Не добавляй его в другие каналы: первая полученная публикация автоматически закрепит источник.
- Публикуй и распространяй только музыку, на которую у тебя есть необходимые права.

## Проверка

- `GET /api/health` — состояние backend.
- `GET /api/tracks` — каталог (доступен из Telegram Mini App после авторизации).
- `POST /api/telegram/webhook` — Telegram webhook.

## Безопасность

`BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `SESSION_SECRET` и `DATABASE_URL` хранятся только в Environment Render. Никогда не помещай их во frontend, GitHub или публичные сообщения.
